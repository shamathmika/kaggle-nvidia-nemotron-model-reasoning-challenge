## What This Assignment Is

Kaggle hosts a competition where you submit a LoRA adapter for a 30B-parameter NVIDIA language model. The model is tested on logic puzzles (Roman numerals, binary bit-manipulation, unit conversions, ciphers, etc.). Your score = % of puzzles answered correctly.

The baseline demo notebook submits an **untrained** adapter — it just applies LoRA and saves it without any training. This project adds actual SFT training using chain-of-thought reasoning trajectories so the model learns *how* to reason through each puzzle type.

---

## Pipeline

```
Step 1: Reasoning trajectories
  train_reasoning_v5.jsonl  ←  pre-generated by professor (8,569 examples)
  Each example: puzzle prompt + short reasoning chain + correct answer

Step 2: SFT training  (nvidia-nemotron-sft-training.ipynb)
  Format: "System / User: prompt / Assistant: reasoning → \boxed{answer}"
  LoRA rank 32, alpha 64, 2 epochs, cosine LR

Step 3: Submit
  submission.zip → Kaggle evaluates with vLLM at temperature=0

Step 4 (optional): Evaluate locally before submitting
  compare_lora_before_after_v2.py  — uses NVIDIA API (free credits)
```

## How to Run — Kaggle (Recommended, Free)

Kaggle gives **30 GPU hours/week free** (T4 × 2 = 32 GB total).

### One-time setup

1. **Upload `train_reasoning_v5.jsonl` as a private Kaggle dataset**
   - Go to kaggle.com → Datasets → New Dataset
   - Upload `CoderGym/Nemotron/train_reasoning_v5.jsonl`
   - Set dataset title/slug to `nemotron-reasoning-data`
   - Keep it private

2. **Create a new Kaggle notebook**
   - Go to the [competition page](https://www.kaggle.com/competitions/nvidia-nemotron-model-reasoning-challenge) → Code → New Notebook
   - Or go to kaggle.com/code → New Notebook

3. **Add data sources** (via the right panel → Add data):
   - Competition data: `nvidia-nemotron-3-reasoning-challenge`
   - Model: search `metric/nemotron-3-nano-30b-a3b-bf16`
   - Your private dataset: `nemotron-reasoning-data`

4. **Enable GPU**
   - Right panel → Accelerator → GPU T4 × 2 (free tier)
   - If the competition provides A100 access, use that instead

5. **Copy notebook contents**
   - Paste the cells from `nvidia-nemotron-sft-training.ipynb` into your Kaggle notebook
   - Or: File → Import Notebook → upload the `.ipynb` directly

6. **Run All** — expect ~3–5 hours for 2 epochs on T4 × 2

7. **Submit**
   - After the notebook finishes, go to the competition page → Submit Prediction
   - Select `submission.zip` from the notebook output

## Evaluating Before You Submit

Use `CoderGym/Nemotron/compare_lora_before_after_v2.py` to test your adapter on training examples without spending Kaggle submission quota.

### Get a free NVIDIA API key
1. Go to [build.nvidia.com](https://build.nvidia.com/models) → sign up for free
2. You get free credits to call models like DeepSeek, GLM, Gemma via the NVIDIA API

### Run the comparison script
```bash
export NVIDIA_API_KEY="nvapi-xxxx"

python CoderGym/Nemotron/compare_lora_before_after_v2.py \
  --train_csv CoderGym/Nemotron/train.csv \
  --num_samples 30 \
  --sample_mode task_balanced \
  --remote_models "deepseek-ai/deepseek-v3.2,z-ai/glm4.7" \
  --nvidia_api \
  --output_jsonl outputs/compare.jsonl \
  --summary_json outputs/summary.json
```

This runs your LoRA model vs. strong NVIDIA-hosted models on 30 random training examples and prints accuracy per task type. Use it to sanity-check before submitting.

## Future Extension: Weight Averaging

If multiple students train LoRA adapters independently, their weights can be averaged:

```python
# Conceptual — average two adapter checkpoints
import torch
from peft import PeftModel

adapter_a = torch.load("adapter_a/adapter_model.safetensors")
adapter_b = torch.load("adapter_b/adapter_model.safetensors")
averaged  = {k: (adapter_a[k] + adapter_b[k]) / 2 for k in adapter_a}
```

This can improve generalization without additional training. Out of scope for this submission but worth exploring.
